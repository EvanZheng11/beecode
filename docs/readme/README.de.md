# BeeCode

BeeCode unterstützt auch [MiniMax Code](../agents/minimax-code.md) und die Verwaltung von [ZCode](../agents/zcode.md)-Skill-Paketen sowie den gesammelten Import von Skills.

[BeeCode herunterladen](https://github.com/EvanZheng11/beecode/releases/latest) · [Server installieren](https://github.com/EvanZheng11/beecode/blob/main/install.sh)

BeeCode ist eine Arbeitsumgebung für Coding-Agenten wie Claude Code, Codex CLI, OpenCode, Gemini CLI und Pi.

Du kannst vorhandene Gespräche importieren, durchsuchen und fortsetzen, Werkzeugaufrufe und Codeänderungen prüfen und Aufgaben in getrennten Git-Worktrees bearbeiten lassen. Editor, Terminal, Browser und eine freie Arbeitsfläche sind integriert. Modelle, MCP-Dienste und Skills lassen sich ebenfalls verwalten.

BeeCode läuft als Desktop-App unter macOS, Windows und Linux sowie als eigenständiger Server oder mit Docker. Öffne ein Projekt, richte den Agenten mit deinem Konto oder API-Schlüssel ein und starte ein Gespräch. Funktionen mit Systemberechtigungen hängen von der Plattform ab.

Danke an die Autoren und Mitwirkenden des ursprünglichen Projekts und an die Betreuer der verwendeten Open-Source-Abhängigkeiten.

Dieses Projekt basiert auf: https://github.com/spacering-net/codeg
