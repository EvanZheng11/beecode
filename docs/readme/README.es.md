# BeeCode

BeeCode también admite [MiniMax Code](../agents/minimax-code.md), la gestión de paquetes de habilidades de [ZCode](../agents/zcode.md) y la importación por lotes de habilidades.

[Descargar BeeCode](https://github.com/EvanZheng11/beecode/releases/latest) · [Instalar el servidor](https://github.com/EvanZheng11/beecode/blob/main/install.sh)

BeeCode es un espacio de trabajo para programar con agentes como Claude Code, Codex CLI, OpenCode, Gemini CLI y Pi.

Permite importar, buscar y continuar conversaciones, revisar llamadas a herramientas y diferencias de código, y organizar tareas en worktrees de Git independientes. Incluye editor, terminal, navegador y lienzo, además de ajustes para modelos, servicios MCP y habilidades.

Funciona como aplicación de escritorio en macOS, Windows y Linux, o como servidor independiente y en Docker. Abre un proyecto, configura el agente con tu cuenta o clave API y empieza una conversación. Las funciones que necesitan permisos del sistema dependen de la plataforma.

Gracias a los autores y colaboradores del proyecto original y a quienes mantienen las dependencias de código abierto.
