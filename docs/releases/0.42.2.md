# BeeCode 0.42.2

## 主要变化

- 统一 Apple 风格界面：基础组件、工作区与设置、侧栏、消息与输入、辅助面板、任务与画布，以及 Markdown、代码和 Mermaid 内容表面。
- 终端跟随主题和工作区背景更新，保留现有 PTY 实例；存量业务对话框显式保留原宽度。
- 提问等待与安全停止：区分上游撤回和本地取消，普通队列不再解除问题超时门禁；新的委派、任务和自动化遵守待答／停止状态，显式人类输入才恢复。
- ACP 连接错误展示可读的后端原因，避免 Web 端显示 `[object Object]`；OpenCode 旧版运行时错误保留版本与设置入口。
- 切换界面语言只更新连接错误文案，不触发失败连接的自动重试。

## 配置与已知边界

- OpenCode 只支持 2.x；检测到 PATH 中的 1.x 时会拒绝启动并提示更新。现有受管 2.x 安装可继续使用。
- DeepSeek Harness 模型与提供商是一对路由选择；不同路由需要各自可用的凭据。同名模型不会自动复制或混用提供商密钥，本版不迁移用户的模型配置。
- Claude Code 的新增报错尚未复现，不能宣称本版已修复该报错。
- 上游已撤销的提问 RPC 不能继续接收答案；安全停止不等于让失效请求无限等待。
- 本机 UI 检查和静态回归不代表全部跨平台 WebView、真实 PTY／Git 写入、画布拖拽持久化及全部业务交互已验收。
