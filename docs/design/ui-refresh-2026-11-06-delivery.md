## P6 颜色例外

守卫不是整文件免检：十六进制按路径和准确颜色登记，新增颜色仍会失败。

- `agent-icon.tsx` / `vscode-icon.tsx`：外部工具官方品牌 SVG，非应用主题装饰色。
- `conversation-tag-form-dialog.tsx` / `custom-style-section.tsx`：任意用户拾色及色样/回退，不改变用户数据。
- `git-log-graph-cell.tsx`：多分支身份色，不等于单一应用主色。
- `window-controls.tsx`：Windows 原生关闭按钮系统交互色。
- `app/layout.tsx`：预水合前独立深色防闪回退，不能依赖尚未应用的主题属性。
- `mermaid-theme.ts`：CSS 色解析失败时必须保留的既有明暗固定调色板；正常渲染走动态 token。
- 白色二维码底及不随明暗变化的实心前景已提取为 `qr-surface` / `solid-foreground`。任意用户头像/标签的前景、Windows 关闭按钮白字有其对比语义，不直接以主题前景替换。
- 模板扫描发现的 Shimmer `#0000` 已替换为等价 `transparent`，未加入例外。
